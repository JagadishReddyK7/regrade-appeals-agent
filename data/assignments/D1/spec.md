# D1: String utilities

Write a module `strings_utils.py` with two functions.

## `count_vowels(text: str) -> int`
Return the number of vowels (a, e, i, o, u) in `text`, ignoring case.
An empty string has 0 vowels.

## `reverse_words(text: str) -> str`
Return the words of `text` in reverse order, separated by single spaces.
Leading, trailing and repeated whitespace is ignored. An empty string gives `""`.
